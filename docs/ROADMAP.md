# FlowCraft AI Roadmap

## V0.1 Runnable Prototype

Goal: prove the end-to-end loop works.

Included:

- Screenshot upload and paste upload.
- Scenario and preference controls before generation.
- DeepSeek-backed generation path.
- Generated prototype preview.
- FlowCraft diagnosis panel.
- Local project saves and result recovery.

## V0.2 FlowCraft Product Shell

Goal: make the app feel like FlowCraft AI instead of a lightly modified
screen-to-code tool.

Planned work:

- Redesign the first screen as an interaction design brief builder.
- Rework the result page around reference, prototype, and decision diagnosis.
- Reduce inherited UI that is not central to FlowCraft's product story.
- Improve project-library visibility and naming.

## V0.3 Interaction State Coverage

Goal: make state coverage a real product capability.

Planned work:

- Detect state coverage in the generated DOM.
- Show which states are covered or missing.
- Add jump points for default, hover/focus, loading, empty, error, success,
  disabled, and confirmation states.
- Add one-click regeneration prompts for missing states.

## V0.4 Project History

Goal: make FlowCraft usable across multiple design attempts.

Planned work:

- Improve local project management.
- Add version labels and notes.
- Add export bundles.
- Prepare a path for account-based or cloud storage later.

## V0.5 Demo Ready

Goal: make the project presentable to other people.

Planned work:

- Curated examples.
- Demo screenshots or short walkthroughs.
- Cleaner onboarding copy.
- Better error states for missing API keys and backend connectivity.
