# Product Positioning

## One-line Position

FlowCraft AI is an AI interaction design workspace that turns product
screenshots into interactive prototypes with design-decision explanations.

## Target Users

FlowCraft is best suited for people who already have some UI judgment and want
to quickly explore interaction directions:

- Product designers validating interaction ideas.
- Founders turning references into quick prototypes.
- Product managers comparing flows and edge states.
- Students or builders learning how interaction decisions affect experience.

## Difference From Screenshot-to-Code

Screenshot-to-code tools primarily answer:

> Can this screenshot be recreated as code?

FlowCraft AI should answer:

> What interaction experience should this reference become, what states are
> missing, and what should be optimized next?

## Difference From Figma

Figma is a full design platform for precise visual creation and collaboration.

FlowCraft AI is not trying to replace Figma. It is focused on the earlier and
faster loop:

1. Start from a reference screenshot.
2. Pick a product scenario.
3. Generate an interactive prototype.
4. Inspect state coverage and design tradeoffs.
5. Iterate quickly.

## Product Principles

- Interactive before decorative.
- State coverage before pixel perfection.
- Explain decisions, not only output code.
- Keep the workflow fast enough for early product exploration.
- Preserve project versions so iteration does not erase working checkpoints.
